# Eigen 上手练习

这个目录不是作业，是熟悉 Eigen 操作的沙盒。改坏了不影响 `hw/`。

## 运行

在 `sandbox` 目录下：

```bat
run.cmd
```

它会用 g++ 编译 `eigen_basics.cpp` 并运行。

## 十步操作

`eigen_basics.cpp` 按顺序演示：

1. `Vector3f`：三维列向量
2. `Matrix3f` + `<<`：按行填矩阵
3. `A(0,1)`：下标从 0 开始
4. `Identity()` / `Zero()`
5. `A * u`：矩阵乘向量
6. `A.transpose()`
7. 构造作业 0 的旋转矩阵 `R`
8. 构造作业 0 的平移矩阵 `T`
9. `R * p`、`T * R * p`
10. `M = T * R`，以及 `M * p`

## 自己改着玩

- 把 `theta` 改成 `90.0f / 180.0f * PI`，预测并验证 `R * p`。
- 把 `p` 改成 `(1, 0, 1)`，看结果怎么变。
- 把 `M = T * R` 改成 `M = R * T`，比较 `M * p` 和原来的差别。
- 把 `R` 的 `(0,1)` 改成 `+s`，看旋转方向反了没有。

## 和作业 0 的关系

`hw/hw0/main.cpp` 里的 `R`、`T` 就是这里的第 7、8 步。把这两段抄过去，只改数值/变量名即可；`M = T * R` 不要动。
