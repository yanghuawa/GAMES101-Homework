# 作业 0：齐次坐标与二维变换

## 题目

点 \(P=(2,1)\)，先绕原点**逆时针**旋转 \(45^\circ\)，再平移 \((1,2)\)。用齐次坐标计算变换后的点，并用 Eigen 验证。

手算答案：\((1.7071,\ 4.1213)\)。

## 1. 为什么需要齐次坐标

二维里缩放、旋转都能写成 \(2\times2\) 矩阵：

\[
S=\begin{bmatrix}s_x&0\\0&s_y\end{bmatrix},\qquad
R(\theta)=\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}
\]

但平移不行：

\[
\begin{bmatrix}x\\y\end{bmatrix}\mapsto\begin{bmatrix}x+t_x\\y+t_y\end{bmatrix}
\]

这不是线性变换（原点被移动了），不存在一个 \(2\times2\) 矩阵 \(M\) 使 \(M\begin{bmatrix}x\\y\end{bmatrix}=\begin{bmatrix}x+t_x\\y+t_y\end{bmatrix}\) 对所有 \(x,y\) 成立。

解决办法：**升一维**。点写成 \((x,y,1)^T\)，向量写成 \((x,y,0)^T\)，所有变换都变成 \(3\times3\) 矩阵：

\[
\begin{bmatrix}x'\\y'\\1\end{bmatrix}
=
\begin{bmatrix}a&b&t_x\\c&d&t_y\\0&0&1\end{bmatrix}
\begin{bmatrix}x\\y\\1\end{bmatrix}
\]

最后一行恒为 \((0,0,1)\)，所以结果仍然是 \((x',y',1)\)。这个“多出来的一维”就是齐次坐标。

> 点的 \(w=1\)，向量的 \(w=0\)。这样平移只作用于点，不作用于向量（方向不应该被平移改变）。

## 2. 旋转矩阵

逆时针旋转 \(\theta\)：

\[
R(\theta)=
\begin{bmatrix}
\cos\theta&-\sin\theta&0\\
\sin\theta& \cos\theta&0\\
0&0&1
\end{bmatrix}
\]

验证：\(\theta=90^\circ\) 时 \(R=\begin{bmatrix}0&-1&0\\1&0&0\\0&0&1\end{bmatrix}\)，作用在 \((1,0,1)\) 上：

\[
R\begin{bmatrix}1\\0\\1\end{bmatrix}=\begin{bmatrix}0\\1\\1\end{bmatrix}
\]

\((1,0)\) 转到了 \((0,1)\)，是逆时针，正确。

## 3. 平移矩阵

\[
T(t_x,t_y)=
\begin{bmatrix}
1&0&t_x\\
0&1&t_y\\
0&0&1
\end{bmatrix}
\]

## 4. 组合顺序

“先旋转，再平移”写成矩阵：

\[
M = T \cdot R
\]

因为矩阵从右往左作用：

\[
M p = T(Rp)
\]

先对 \(p\) 做 \(R\)，再对结果做 \(T\)。**后做的变换写在左边。**

如果写成 \(R\cdot T\)，就是先平移再旋转，结果不同：

- 先旋转再平移：绕原点转，然后整体挪走。
- 先平移再旋转：点先被挪到别处，再绕原点转，轨迹完全不一样。

## 5. 手算

\[
\cos45^\circ=\sin45^\circ=\frac{\sqrt2}{2}\approx0.70710678
\]

先旋转：

\[
Rp=
\begin{bmatrix}
c&-s&0\\s&c&0\\0&0&1
\end{bmatrix}
\begin{bmatrix}2\\1\\1\end{bmatrix}
=
\begin{bmatrix}2c-s\\2s+c\\1\end{bmatrix}
=
\begin{bmatrix}1.41421-0.70711\\1.41421+0.70711\\1\end{bmatrix}
=
\begin{bmatrix}0.70711\\2.12132\\1\end{bmatrix}
\]

再平移：

\[
TRp=
\begin{bmatrix}1&0&1\\0&1&2\\0&0&1\end{bmatrix}
\begin{bmatrix}0.70711\\2.12132\\1\end{bmatrix}
=
\begin{bmatrix}1.70711\\4.12132\\1\end{bmatrix}
\]

精确值：

\[
x=1+\frac{\sqrt2}{2}\approx1.7071,\qquad
y=2+\frac{3\sqrt2}{2}\approx4.1213
\]

## 6. 写成 Eigen

Eigen 的 `<<` **按行**填充：

```cpp
Eigen::Matrix3f R;
R << c, -s, 0,
     s,  c, 0,
     0,  0, 1;

Eigen::Matrix3f T;
T << 1, 0, 1,
     0, 1, 2,
     0, 0, 1;

Eigen::Matrix3f M = T * R;       // 先 R 后 T
Eigen::Vector3f p(2.0f, 1.0f, 1.0f);
Eigen::Vector3f q = M * p;

std::cout << q.x() << " " << q.y() << std::endl;
```

注意：

- `Eigen::Vector3f p(2,1,1)` 的第三个分量是齐次坐标的 \(w=1\)，不是 z。
- Eigen 用**列向量**，`M * p` 的乘法顺序和纸上一致，不需要转置。
- `Matrix3f` 默认是 float；要更多小数位可以用 `Matrix3d` / `Vector3d`。
- 角度用弧度：`theta = 45.0f / 180.0f * PI`。

## 7. 常见错误

| 错误 | 现象 |
| --- | --- |
| 平移写在最后一行 `[1,0,0; 0,1,0; tx,ty,1]` | 这是行向量约定，和 Eigen 的列向量不匹配，结果错 |
| 忘记 \(w=1\)，直接把点当二维向量 | 平移矩阵的第三列不生效 |
| 写成 `R * T` | 先平移后旋转，结果不是题目要求 |
| 角度没转弧度 | 45 弧度，结果完全不对 |
| 旋转方向搞反 | 得到 \((2.7071, 1.2929)\) 之类的镜像结果 |
